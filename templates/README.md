# Artifact registry

One line per output artifact. Adding an artifact: add its template file here and
add a row below. No change to the behavior rules in `COACH-PROMPT.md` is needed —
this registry is the extension seam (ENG-OCP-1).

| Artifact | Template | Milestone |
| --- | --- | --- |
| Idea Brief | `IDEA-BRIEF.md` | Discovery complete per BR-101 |
| Count Ledger | `COUNT-LEDGER.md` | Any count supplied or changed |
| Experiment Card | `EXPERIMENT-CARD.md` | Experiment designed, before running |
| MVP Brief | `MVP-BRIEF.md` | Experiment Complete and decision stated |
